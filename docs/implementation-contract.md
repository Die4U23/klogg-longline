# 实施契约

日期：2026-10-17。以下为候选实现的边界；实测是否满足目标，另见验证报告。

## 分阶段进入条件

固定上游已经复现 4 GiB 相对跨度退出、移动后追加偏移错误、空范围读取异常；实际 64 MiB 单行读取分配整个行缓冲，16 MiB GUI 换行发生严重内存增长及分配失败。这些独立同类样例构成进入实现的证据，不宣称复现或关闭原 macOS issue。

## 数据与显示

- 文件偏移使用有符号 64 位字节位置，行号使用现有 64 位类型。字符位置与字节位置分别表示。
- 复用已有行索引；末行的人工 LF 端点不能被当成文件中的真实字节读取。
- 新的静态文件读取会话固定文件身份、大小、修改时间与数据代次。在开始、读块边界及结束检查；短读、替换、截断和重载必须明确终止。普通文件不提供针对恶意恢复时间戳的事务快照保证。
- 超长行显示采用有明确范围标记的有限窗口。复制和快速查找不能把这个窗口冒称为完整行；完整字面搜索独立读取文件。
- 每行窗口上限 16 KiB 原始字节；每帧后台任务最多 128 KiB 原始输入、256 行。旧缓存及进行中的新帧分别存活；制表符最坏扩展 8 倍，UTF-16 另计。窗口列号是局部显示列，字节锚点经 UTF-8/制表符转换后定位。

## 搜索

- 首版有界路径保证非空、区分大小写、非排除、非布尔、无预过滤的 UTF-8 字面串检索；模式中含 LF 的跨行匹配不属于按行语义。
- 模式长度公开限制为 1 MiB UTF-8 字节。跨块状态不能依赖整行缓冲；同一行多次命中只保留一个行结果和首次命中字节位置。
- 对不支持的超长行模式，在进入匹配器前明确报错；普通行原有编码和模式保留并回归。
- 固定读块与模式状态、暂存结果分别计量。128 MiB 是数据通路目标，不是进程 RSS 上限。结果达到预算时以 partial 结束。
- 长行路径默认读块 1 MiB，允许的内部测试上限 4 MiB；匹配行上限 65,536，只保存每行第一个字节位置。达到上限后遇到额外命中才返回 partial。
- 普通 TBB 路径先利用索引规划最大 4 MiB 整行批次，在读取前取得 RAII 租约。活跃租约总额不超过 128 MiB：直接 UTF-8 路径保守预留 `3R + 32N + 64 KiB`，批量转码路径预留 `9R + 32N + 64 KiB`，其中 R 为原始字节数，N 为行数。租约随最后一份块引用释放，包含生产者、队列、匹配和待合并阶段。
- 普通路径累计命中位图、行索引、正则内部空间和 Qt/TBB 框架不计入上述活跃块预算，不能据此声称总内存有 128 MiB 上限。其峰值指标是保守预留量，不是逐次分配测量。
- 终态区分 complete、cancelled、partial、failed、source_changed。失败和取消不能写入完整结果缓存。
- 每个搜索请求携带代次；新请求、清空和切换后，不接受旧代次进度或结果。清理仍须释放对应任务的读者引用。

## 验证

相同输入和构建配置对照 baseline/candidate；原始文件前后哈希一致。实际搜索行集合对照独立参考程序。分别报告组件测试、真实文件集成、真实 Qt 控件操作、资源测量和未覆盖平台。普通日志至少三轮取中位值，超过 10% 回退门槛时调整路径或说明未通过，不能仅挑选有利轮次。
